# statusquofff.github.io

Site de portfólio básico criado automaticamente.

Como personalizar:

1. Abra `index.html` e substitua "Seu Nome", o texto de apresentação e os links (GitHub, LinkedIn, email) pelos seus dados.
2. Substitua as imagens de placeholder dos projetos por imagens reais ou screenshots.
3. Atualize as descrições dos projetos e adicione links para os repositórios ou páginas de demonstração.
4. Para ajustar estilos, edite `assets/css/styles.css`.

Publicação:

Este repositório está pronto para GitHub Pages — ao manter `index.html` na raiz e ativar Pages nas configurações do repositório, o site será publicado em `https://<seu-usuario>.github.io/<nome-do-repo>/` ou no domínio configurado.

- Trocar textos e cores por você (me forneça o conteúdo).
- Adicionar uma seção de blog ou uma página de projetos detalhada.
- Configurar um arquivo CNAME para domínios personalizados.
